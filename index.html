Cómo publicar en GitHub Pages
  1. Inicia sesión en github.com
  2. Clic en + → New repository
  3. Nómbralo ranfi y marca Public → Create
  4. Clic en Add file → Upload files
  5. Arrastra este archivo HTML y haz Commit changes
  6. Ve a Settings → Pages → Branch: main → Save
  7. Tu URL será tuusuario.github.io/ranfi
  8. Abre esa URL en el celular y agrégala a la pantalla de inicio
